# Rpg_8DiceSystem

Ce projet me sert de base pour tester un nouveau système de RPG/Dungeon Crawler avec des éléments d'exploration, s'inspirant des jeux de rôle plateaux comme HeroQuest, Divinity Original Sin The Boardgame ou Les demeures de l'épouvante et se basant sur des dés à 8 faces.

C'est un projet encore en développement. Je posterai un lien vers une version jouable dès qu'elle sera disponible.
